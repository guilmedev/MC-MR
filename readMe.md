## How it Works

Using a Meta Quest 3 and in a MixedReality scope the app uses the folowing technologies:

- [Meta quest passthrough layer](https://developers.meta.com/horizon/documentation/unity/unity-passthrough/)
    - Hability to view the world beyond the camera
- [Meta Passthrough Camera API](https://github.com/xrdevrob/QuestCameraKit#pca-samples) 
    - To have colorPicker from camera
- [Unity animation rigging](https://docs.unity3d.com/Packages/com.unity.animation.rigging@1.0/manual/index.html)
    - Create custom poses for the model
